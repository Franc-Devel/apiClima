# FAUVOR Clima

## Rol dentro del catálogo

Consulta de clima.

Aplicación React que consulta Open-Meteo por ciudad. La demo meteorológica de la landing tiene una presentación adicional; no todas sus visualizaciones equivalen a capacidades del frontend de este repositorio.

## Identidad

El nombre visible del producto es **FAUVOR Clima**. Se conserva la URL `Franc-Devel/apiClima` para mantener los enlaces históricos. El símbolo y los iconos provienen del kit original FAUVOR. La paleta utiliza marfil, blanco cálido, bronce y dorado; los estados positivos usan un oliva sobrio.

Las portadas son ilustraciones conceptuales, no capturas de pantalla. No acreditan clientes, cifras de uso, resultados comerciales ni funciones que no estén implementadas.

## Ejecución

`npm ci`, `npm run dev` y `npm run build`.

## Alcance y límites

El radar y los instrumentos de la demo no deben presentarse como mediciones de un servicio meteorológico certificado. La consulta real depende de disponibilidad de la API y de la conexión.

FAUVOR Flow es un proyecto independiente. No conecta automáticamente estas bases o servicios: cualquier integración futura debe implementarse y verificarse.
